# Простейший sip говорун
Под капотом просто стейт машина, которая узнает у пользователя адрес отправления и адрес назначения, прощается 
и вызывает апи запуска процесса такси (он должен уже быть в wfe)

Cборка самого исполняемого jar стандартна:

```shell
mvn clean package
```
в app/target появится файл app-1.0.0.jar

Но для запуска нам пондобится sip прокси rhvoice и vosk:

* Собираем прокси как описано в проекте (pjsip_proxy). На выходе у нас будет файл pjsip_proxy и директория libs с зависимостями, их складываем в директорию 1sip-bot-dock1/app/_app_/proxy
* Скачиваем и распаковываем модель vosk-model-ru-0.42 для библиотеки vosk (https://alphacephei.com/vosk/models) (без впн еле еле качает). Директория будет: 1sip-bot-dock1/app/_app_/vosk-model-ru-0.42
* И закидываем рядом 1sip-bot-dock1/app/_app_/app-1.0.0.jar

Все готово для запуска, преходим в директорию 1sip-bot-dock1 и

```shell
docker-compose up -d
```
У вас соберется и запустится контейнер с приложением и рядом подымется rhvoice, после чего можно будет звонить и заказывать такси
